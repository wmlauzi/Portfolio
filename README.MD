# Wanangwa Mlauzi — Portfolio

Personal portfolio showcasing web development projects, practical agritech products, technical capabilities and ways to get in touch.

## Built with

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts (Space Grotesk, Inter and JetBrains Mono)

This is a lightweight static website. It has no framework, package dependencies or build step.

## Run locally

Open `index.html` in a browser, or serve the repository root with any local static file server.

## Deploy to Vercel

Import this repository into Vercel and deploy it as a static site:

- Framework preset: **Other**
- Build command: leave empty
- Output directory: leave empty
- Root directory: repository root

The `index.html` file is at the repository root. Keep the `assets/` directory alongside it so profile and project images continue to load. The root-level `404.html` provides a branded not-found page.
