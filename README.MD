# Wanangwa Mlauzi — Portfolio

A static portfolio presenting web development and IT support as equally important professional services.

## Run locally

Open `index.html` in a browser. The site has no build step or package dependencies.

## Deploy to Vercel

Import this repository into Vercel and deploy it as a static site. Keep the framework preset set to **Other** and leave the build command and output directory empty; `index.html` is at the repository root.

The profile image uses the relative path `assets/images/Profile-image.png`. Keep the `assets/` directory alongside `index.html` when deploying.
The root-level `404.html` provides a branded not-found page on Vercel deployments.
